# Kendal House & St Timothy's Ministry Website

Website for **Kendal House** (intentional Christian community & subsidised housing) and **St Timothy's Ministry Roles** (youth, intermediate, and children's support workers) in Burnside, Christchurch.

## Pages

- `index.html` — Homepage
- `accommodation.html` — Kendal House Accommodation details
- `roles.html` — Paid Ministry Roles at St Timothy's
- `style.css` — Site styling and design system

## Local Development

You can open `index.html` directly in any web browser, or serve it locally using Python:

```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080`.
